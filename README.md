# impuls_technique

# Сайт продажи техники

Данный проект был разработан во время внутренней практики на 3 курсе РКЭ.

## О проекте
Это веб-сайт для продажи техники с реализованной серверной частью (PHP) и подключённой базой данных (MySQL). Проект включает в себя как пользовательскую часть, так и административную панель.

## Функционал

### Пользовательская часть:
- Регистрация и авторизация пользователей  
- Просмотр каталога товаров  
- Поиск товаров по сайту  
- Фильтрация товаров по категориям и параметрам  

### Административная панель:
- Добавление и редактирование товаров  
- Просмотр зарегистрированных пользователей  
- Просмотр заказов  

## База данных
Проект работает с подключённой базой данных.  
Структура базы и тестовые данные представлены в файле database.sql.

## Технологии
- HTML / CSS / JavaScript  
- PHP  
- MySQL  

## Примечание
Изначально проект был размещён на InfinityFree и работал с серверной логикой.  
В данном репозитории представлен код проекта и его структура для демонстрации в портфолио.

Некоторые динамические функции могут не работать без серверной среды.
